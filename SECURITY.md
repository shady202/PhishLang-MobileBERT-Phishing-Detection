# Security Policy

## Scope

This repository is an educational phishing-detection experiment. It is not an operational security product and does not accept live credentials, private datasets, or real-world incident evidence.

## Reporting a Concern

Do not open a public issue containing credentials, personal data, private URLs, or live malicious infrastructure. Remove sensitive details and contact the repository owner privately through their GitHub profile.

## Safe Testing

Use synthetic or explicitly licensed samples in an isolated environment. Never submit real credentials to a page or endpoint as part of testing this project.
